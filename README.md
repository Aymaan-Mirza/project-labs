# project-labs-and-assignments

Collection of labs completed as part of a *Complete Digital IC Design Flow: From Concept to Silicon* course. Each lab builds toward understanding the full ASIC design flow, from RTL design through simulation and verification.

## Why I'm doing this

I'm an Electrical Engineering student working toward a career in ASIC/hardware design. This repo is where I'm building foundational skills in the digital IC design flow, from writing RTL to verifying it works the way it's supposed to. Every lab here represents a step in understanding how a chip actually gets built, not just in theory, but in practice.

## Purpose

This repo tracks my hands-on labs and assignments from the course, focused on practical digital design skills used in real ASIC development, Verilog module design, testbench writing, and simulation verification.

## Tools

- **Language:** Verilog
- **Simulation:** ModelSim
- **Synthesis:** Vivado
- **Editor:** VS Code with TerosHDL
